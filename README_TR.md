# TKPR2 Document Master List Dashboard

## Çalıştırma

1. ZIP dosyasını yeni ve boş bir klasöre tamamen çıkarın.
2. Bilgisayarda **Python 3.15** kurulu olduğundan emin olun.
3. `run_dashboard.bat` dosyasına çift tıklayın.
4. İlk çalıştırmada gerekli paketler internet üzerinden kurulabilir; bu işlem birkaç dakika sürebilir.
5. Kurulum tamamlandığında Streamlit dashboard tarayıcıda açılır.

## Paket içeriği

- `app.py` — tek Python kaynak dosyası
- `Document Master List - TKPR2 (for RET review and update)_20260925 1.xlsx` — güncel veri kaynağı
- `run_dashboard.bat` — Windows başlatıcısı
- `requirements.txt` — gerekli Python paketleri
- `README_TR.md` — bu kullanım notu

Uygulama Excel dosyasını yalnızca kendi klasöründen okur. Excel dosyasının ve `app.py` dosyasının adını değiştirmeyin.

Bir hata oluşursa başlatıcı pencereyi açık tutar; ekrandaki hata metni incelenebilir.
